The machinery: four moves.

No new silo, no rip and replace. Start from the systems already running and make the funnel read from one model.

MOVE 01

Resolve identity first

Every touch lands on one account record before anything else happens. Same company, one owner, one status, whichever system the signal came through.

Sketched as an n8n workflowMatch the signal to the account, attach context, post it to Slack for a human to confirm.
MOVE 02

A score you can open up

A sales leader can click in and see why: fit, intent, engagement, and the signals behind each. If the model cannot explain itself, reps will not trust it.

Sketched as an n8n workflowRecompute on new signals, publish factor weights, log every change so the score has a history.
MOVE 03

One lifecycle, shared definitions

SAL and SQL mean the same thing in every report because they read the same record. Routing SLAs fire from the model, not from memory.

Sketched as an n8n workflowStage changes trigger routing, SLAs and alerts from one definition.
MOVE 04

Report from the model

Conversion analytics stop being a monthly reconciliation. When the funnel runs on one record, SAL to SQL reporting is a view, not a project.

Sketched as an n8n workflowNightly checks flag duplicates and drift; dashboards read the fields the workflows write.
