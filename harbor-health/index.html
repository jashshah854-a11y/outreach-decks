The machine

A project machine built for review season.

Sketched with the tools I actually run: ClickUp holds the schedule, n8n moves the packets, Slack keeps the heartbeat. No new platform, no migration.

MOVE 01

Review slots are booked first

Capacity is reserved in ClickUp before campaigns exist. Reviewers get first pick of the calendar, not whatever is left in late October.

The moveSlack pings each reviewer two days before their slot, packet attached. Nobody is surprised the morning of.
MOVE 02

Packets arrive complete

An n8n workflow assembles the submission from the brief: assets, copy, source links, approval history. Reviewers read one file, not five threads.

The moveA checklist runs before anything is sent. An incomplete packet never reaches a gate, so a gate never sends one back.
MOVE 03

One launch date, always current

Every launch date lives in a single ClickUp dashboard. When a gate slips, the ripple shows up the same minute, not the same week.

The moveThe owner sees the new critical path and rebooks immediately, instead of finding out on Nov 2.
Reviews protect members and the brand. The machine protects the date.
