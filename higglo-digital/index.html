The machine

Three gates I would own on day one.

Built as n8n workflows on my own stack: watch the break, fix it before the report, prove it in the readout.

GATE 01

Pre-launch QA

Before any spend, an automated checklist tests every form, route, number, and pixel. Nothing launches half-wired.

The ops playOne checklist per launch, run from ClickUp, results attached to the launch ticket.
GATE 02

In-flight monitoring

A daily workflow watches for dead forms, number drift, and tracking drop-offs. Alerts land in Slack the hour it breaks, not at month end.

The ops playn8n jobs poll the live surfaces and page the owner when a gate regresses.
GATE 03

Reporting cadence

One definition of a qualified inquiry, one dashboard, one weekly read. No rebuilt decks, no disputed numbers.

The ops playA single source of truth that updates itself, so the readout is a review, not a reconstruction.
