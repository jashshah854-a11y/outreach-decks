The machine

One score. Every Monday.

An Engine Health Score that turns the Day 1 audit into a standing heartbeat, built from the systems the client already runs.

1

PullRead the systems you already have

An n8n workflow pulls weekly, read-only exports from the platforms the client already runs. No new instrumentation, no migration, no rip and replace.

2

ScoreFive inputs, one number

The same formula every week: routing accuracy, tracking coverage, scoring stability, data hygiene, attribution sanity. One composite, five explainable parts.

3

ActRoute the fix before the quarter notices

The score lands in ClickUp each Monday. Any input that crosses its band pings Slack with the fix and the owner, so drift gets caught in days, not discovered in the next audit.

The rule: an audit should never be the last measurement. It should be the first one, repeated weekly until the next audit makes it better.
